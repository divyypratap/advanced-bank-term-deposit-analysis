## 📊 Project Overview

This project performs complete **Exploratory Data Analysis (EDA)** followed by **Predictive Modeling** using Logistic Regression to identify key drivers of term deposit subscriptions.

### Key Objectives:
- Deep customer segmentation and behavior analysis
- Feature engineering and importance ranking
- Build and evaluate classification model
- Deliver actionable business insights for targeted marketing

## 🔍 Key Insights

- Only **11.27%** subscription rate (highly imbalanced)
- **Students** and **Retired** customers show highest conversion
- **Call duration** is the strongest predictor
- Economic indicators (`euribor3m`, `emp.var.rate`) significantly influence decisions
- Cellular contact performs much better than telephone
